# Contributing

Thanks for improving agent-skills. Each skill lives in its own folder under `skills/`.

## Good contributions

- Fixes and clearer wording in an existing skill
- New examples for a skill
- New skills, one folder each, with a `SKILL.md`
- Translations

## Ground rules

1. Keep skills short and readable.
2. No secrets, account IDs, hostnames or internal tool names.
3. Anything that creates, changes or deletes must ask for confirmation first and offer an undo.
4. Say what you verified and link your sources.

## How to submit

1. Fork the repo and create a branch.
2. Make your change under `skills/<name>/`.
3. Add a line to the skill's `CHANGELOG.md`, if it has one.
4. Open a pull request and describe the problem it solves in one or two sentences.

## Conduct

Be kind and specific. Critique the change, not the person.
